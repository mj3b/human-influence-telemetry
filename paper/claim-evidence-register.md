# Claim-Evidence Register

The machine-readable register is [`evidence/claim-evidence-map.json`](../evidence/claim-evidence-map.json). It is authoritative for the v0.6.5 mapped set.

The register covers H1 through H9 and four paper claims. Each record declares exact evidence locators, five evidence-fitness dimensions, dependencies, limitations, reversal conditions, five gate states, and conclusion eligibility. The generated audit report records the computed states.

Unmapped prose receives no conclusion authority from this audit. A later release must add a claim to the map before treating the audit as support for that claim.
